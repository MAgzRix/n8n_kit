📡 Автоматизация процессов (Альфа-имена)

Браузерная версия n8n-workflow «Автоматизация процессов (Альфа-имена) — оптимизированная»: приём заявки → валидация → согласование менеджером → реестр, карточка заявки, файлы операторов, уведомления.

⚠️ Демо-режим по умолчанию: вместо реальных вызовов Google/Telegram логируется ход выполнения (консоль операций ниже). Реальные вызовы API включаются константой USE_REAL_API_CALLS в начале скрипта.
